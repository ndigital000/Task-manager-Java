# Task Manager Java

**EN** | [ITA](#ita)

## Description
A simple command-line Task Manager built in Java.
This project was built to practice Object-Oriented Programming concepts in Java.

## Features
- Add a new task
- View all tasks with their status
- Mark a task as completed
- Delete a task

## Technologies Used
- Java
- OOP (Object-Oriented Programming)
- ArrayList
- Exception Handling

## How to Run
1. Clone the repository
2. Open the project in IntelliJ IDEA
3. Run the Main class

## Project Structure
- `Task.java` — represents a single task object
- `TaskManager.java` — manages the list of tasks
- `Main.java` — handles user input and menu display
